## Existing Models Modified

### `ingestion.Project` — add two fields

```
Project (existing)
├── ... (all existing fields unchanged)
├── workflow_step (IntegerField, default=1)
│   # Analyst's manually set current step (1–7). get_workflow_status() computes
│   # the actual step dynamically; this field allows override.
└── stakeholder_table_stale (BooleanField, default=False)
    # Set True when a new document is extracted after priority table generation.
    # Reset to False when table is regenerated or analyst keeps current version.

Methods (new):
  get_workflow_status() → dict
    # Returns {
    #   current_step: int,   # first incomplete step number (1–7)
    #   steps: [
    #     { number, label, complete, url }
    #   ]
    # }
    # Step completion logic:
    #   1 — complete if initiative_profile.initiative_name non-empty
    #   2 — complete if any Document with status='processed' exists for project
    #   3 — complete if any Entity linked to project via NERRun exists
    #   4 — same condition as step 3
    #   5 — complete if any ReportSection with status='done' exists for project
    #   6 — complete if project.stakeholder_table_stale is False AND
    #             any EngagementNote exists for project (proxy for table generated)
    #   7 — always False (no persistent export record in MVP)
```

### `ner.ReportSection` — add STATUS_STALE choice

```
ReportSection (existing)
├── STATUS_STALE = 'stale'   ← NEW choice added to STATUS_CHOICES
├── ... (all other fields unchanged)
```

State transitions (updated):
```
pending → generating → done
                    → error
done → stale   (flag_stale_report_sections() called after new extraction)
stale → generating  (on re-generate request)
stale → done   (on "keep current version" — status updated, content unchanged)
```

## New Models

### `ner.StakeholderPersona`

One persona card per entity type per project, generated by AI.

```
StakeholderPersona
├── id (UUID, PK)
├── project (FK → Project, related_name='stakeholder_personas')
├── entity_type (FK → EntityLabel, null=True, blank=True)
│   # The entity type this persona represents (e.g. Organization, Person)
│   # null allowed for edge cases (e.g. unlabelled types)
├── persona_name (CharField, max_length=255)
│   # e.g. "The Policy Architect"
├── archetype_label (CharField, max_length=255)
│   # e.g. "Institutional Champion"
├── demographics (TextField)
│   # 2–4 sentence description of the typical demographic profile
├── motivations (JSONField, default=list)
│   # Exactly 3 string items: ["...", "...", "..."]
├── frustrations (JSONField, default=list)
│   # Exactly 3 string items: ["...", "...", "..."]
├── representative_entities (JSONField, default=list)
│   # List of {id: uuid_str, name: str} for up to 10 entities of this type
└── generated_at (DateTimeField, auto_now_add=True)

Meta:
  unique_together = [('project', 'entity_type')]
  ordering = ['entity_type__label']
```

**Validation**:
- `persona_name` and `archetype_label` must not be blank
- `motivations` and `frustrations` must each have exactly 3 items (enforced in service, not DB constraint)
- `representative_entities` is a JSON list — max 10 items enforced in service

### `ner.WorkplanComponent`

A thematic grouping within a project's stakeholder engagement workplan.

```
WorkplanComponent
├── id (UUID, PK)
├── project (FK → Project, related_name='workplan_components')
├── order (PositiveIntegerField, default=0)
│   # Display order within the workplan (0-indexed)
├── title (CharField, max_length=255)
│   # e.g. "Capacity Building and Training"
└── generated_at (DateTimeField, auto_now_add=True)

Meta:
  ordering = ['order']
```

---

### `ner.WorkplanTask`

One actionable task within a workplan component.

```
WorkplanTask
├── id (UUID, PK)
├── component (FK → WorkplanComponent, related_name='tasks')
├── order (PositiveIntegerField, default=0)
├── task_description (TextField)
│   # Full description of the task and its purpose
├── suggested_owner (CharField, max_length=255, blank=True)
│   # e.g. "UNDP Programme Officer"
├── timeline (CharField, max_length=255, blank=True)
│   # e.g. "Q2 2026 — 3 months"
├── dependencies (TextField, blank=True)
│   # Text description of prerequisite tasks or conditions
├── kpis (TextField, blank=True)
│   # Key performance indicators for this task
└── related_entity (FK → Entity, null=True, blank=True, on_delete=SET_NULL)
    # Optionally linked to a known extracted entity
    # Linked via case-insensitive name match at generation time

Meta:
  ordering = ['order']
```
